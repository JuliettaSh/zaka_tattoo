🚀 CÓMO USAR LOCALMENTE:

1. Instalar dependencias:
   npm install

2. Iniciar servidor:
   npm start

3. Acceder a:
   - Sitio: http://localhost:3000
   - Admin: http://localhost:3000/admin.html
   - Clave: zaka2024

💾 CÓMO FUNCIONAN LAS CONSULTAS:

1. Usuario llena formulario en index.html
2. Se envía con fetch a POST /api/consultas
3. Servidor guarda en SQLite
